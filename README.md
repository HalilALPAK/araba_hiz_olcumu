# Araba Hız Ölçümü

Trafik/yol kamerası görüntüsünden geçen araçların hızını görüntü işleme ile tahmin eden bir bilgisayarlı görü denemesi.

![Örnek çıktı](h%C4%B1z.PNG)

## İçindekiler

| Dosya | Açıklama |
|---|---|
| [`hiz.ipynb`](hiz.ipynb) | Video/görüntü karelerinde araç tespiti yapıp, kareler arası konum değişiminden hız tahmini üreten notebook. |

## Kullanılan Teknolojiler

- OpenCV
- Python, Jupyter Notebook

## Kurulum

```bash
pip install opencv-python numpy matplotlib
```
